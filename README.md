# Create-Toroidal
[![Minecraft Version](https://shields.io)](https://minecraft.net)
[![Modloader](https://shields.io)](https://neoforged.net)
[![License](https://shields.io)](LICENSE.txt)

**Create: Toroidal** is a high-fidelity industrial-aerospace, fluid dynamics, and space centrifuge mechanics expansion built specifically for the **Create Mod**, **Valkyrien Skies**, and **Aerodynamics4MC** ecosystems. 

Instead of demanding heavy, server-crashing fluid molecule simulations, this mod runs entirely on optimized **Analytical Vector Force Envelopes** to calculate complex aerodynamic behaviors dynamically on a flat voxel grid.
